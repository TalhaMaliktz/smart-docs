# STATUS: ARCHIVED

This repository represents the legacy V1 monolithic framework for SmartDocs, now succeeded by **Tenetflow**. 

Development has officially transitioned to a highly optimized, decoupled architecture separating the presentation layer, the autonomous agent grid, and the secure data engine. 

* **Core Infrastructure:** The decoupled database and API layer are available publicly at [tenet-backend](https://github.com/TalhaMaliktz/tenet-backend).
* **Live Ecosystem:** To interact with the production-grade zero-trust interface, visit [tenetflow.ai.studio](https://tenetflow.ai.studio).
